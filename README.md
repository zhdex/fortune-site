# 星阑文化 · 命理网站

> 星盘与灯火，皆为懂你。八字 · 紫微斗数 · 每日运势 —— 深奥的古老智慧，翻译成温柔的白话。

## 项目结构

```
星阑文化/
├── shared/            # 前后端【共用】引擎（纯 JS，浏览器与 Node 都可用）
│   ├── charts.mjs     # 排盘：八字（lunar-javascript）+ 紫微（iztro）+ 黄历 + 五行能量/强弱
│   ├── dailyQuiz.mjs  # 每日运势小测验：生肖 + 星座 + 五行 → 能量分 / 幸运色 / 场景宜忌
│   ├── divination.mjs # 一日一卦：八卦、六十四卦全表、梅花易数时间起卦（本卦/变卦/互卦）
│   ├── catalog.mjs    # 商品目录与价格（前后端同源，静态版也同价）
│   └── interpret.mjs  # 演示解读文案 + 流式分片（无后端时的本地回退）
├── server/            # Express 后端
│   ├── index.mjs      # 路由：排盘 / AI 流式解读(SSE) / 模拟支付 / 每日运势
│   ├── charts.mjs     # 转发 shared/charts.mjs（保持旧引用可用）
│   └── ai.mjs         # DeepSeek 解读（JSON mode + 回退演示模板）
├── web/               # React + Vite 前端（星河幻境主题：深空紫 + 金色符印）
│   ├── public/images/        # 主视觉背景（hero-bg.webp/jpg，太极八卦星云）与 ComfyUI 生成的图标/符印
│   ├── src/i18n/             # 三语词库与切换机制（简中 / 繁中 / English）
│   ├── src/components/       # Nav / LangSwitcher / Mandala(SVG 符印) / Icons / StarField / PayModal
│   ├── src/lib/api.js        # 自动探测后端；不可用则回退本地引擎
│   ├── src/pages/            # Home / Fortune(命盘解读) / Daily(当日测验) / Gua(一日一卦) / About
├── assets/            # 素材归档（项目自包含）：source 原始素材 / generated ComfyUI 原图 / screenshots 验收截图
├── .github/workflows/deploy.yml  # 推送到 main 自动构建并部署 GitHub Pages
├── .env.example       # 环境变量样例
└── package.json
```

## 界面与多语言

- **视觉**：**全站共用一张星河法阵底图**（固定定位，首页与内页同一张，只加薄纱不压黑）+ 金色细线符印（纯 SVG，可旋转/呼吸，缩放不糊）+ 五张功能卡（图标为本地 ComfyUI qwen_image_2.1 生成的透明 PNG，转 WebP 后每枚约 10 KB）。
  为保证"图看得见、字也看得清"，直接压在图上的文字都装在玻璃面板里（`.glass` / `.about-body` / `.how` / `.faq` 等）。
- **多语言**：右上角地球按钮切换 **简体中文 / 繁體中文 / English**，选择记入 `localStorage`（`xinglan_lang`），并同步 `<html lang>`；词库集中在 `web/src/i18n/dict.js`，新增语言只需加一个对象 + 在 `LANGS` 登记。
- **可扩展**：首页由 `content` 驱动（服务卡 / 三步流程 / 定价 / FAQ 均为数据段），页面为 hash 路由，新增页面在 `App.jsx` 的 `ROUTES` 里加一项即可。
- **无障碍**：尊重系统 `prefers-reduced-motion`，关闭动画并取消错峰延迟。
- **素材出处**：每张图的原始文件、生成提示词、优化参数都记在 [`assets/README.md`](assets/README.md)，
  换台机器也能照着重做；站点实际引用的图在 `web/public/images/`。

**权限模型**：支付确认后，后端签发带 `scope` 的 HMAC 令牌（`ch:summary` / `ch:love` / `ch:career` / `ch:all` / `daily` / `gua`），

静态托管没有后端时，凭证由浏览器本地签发并同样按 scope 判定——所以 Pages 上的付费流程能完整演示。

## 合规与条款

- **页面**：`#/legal`「免责声明」+「退款政策」全文（简中 / 繁中 / English 三语，文本在 `web/src/i18n/legal.js`）。
- **免责声明 = 单方告知**：只展示，不设「同意 / 不同意」按钮，也不要求任何勾选。
- **退款政策 = 付款前同意**：付款弹窗内展示摘要与勾选框，**必须勾选「我已阅读并同意《退款政策》…」才能点「确认支付」**；
  每次付款都要重新勾选（不预选、不记忆）。
- **查看条款**：弹窗内「查看完整条款」会跳到条款页并**自动滚到退款政策**，页面出现「返回继续支付」按钮，
  点击即回到原页面并重新打开同一笔付款（草稿一并恢复）。
- **入口**：顶部导航「免责声明」（位于一日一卦与关于之间）+ 页脚链接。
- 两份文本均由主上提供，未作删改，仅做了分节排版。

## 快速开始

### 1. 配置 AI（可选）

复制 `.env.example` 为 `.env`，填入 DeepSeek 密钥：

```
DEEPSEEK_API_KEY=sk-你的密钥
DEEPSEEK_MODEL=deepseek-chat
PAY_SECRET=xinglan-demo-secret-2026
PORT=8787
```

> **不填密钥也能跑**：服务器自动进入演示模式，用确定性模板文本 + 模拟流式输出，适合先看效果。

### 2. 启动

```bash
# 后端（端口 8787）
pnpm install
pnpm start          # 或 pnpm dev（--watch）

# 前端开发模式（端口 5188，已代理 /api 到 8787）
cd web
pnpm install
pnpm dev            # 打开 http://localhost:5188

# 或生产构建后由后端直接托管
pnpm run build      # 产物在 web/dist，服务器自动挂载
# 然后只访问 http://localhost:8787 即可
```

## 支付说明（演示占位）

`/api/pay/create` → `/api/pay/confirm` 为**模拟支付**：确认后服务器签发 HMAC-SHA256
解锁令牌，前端存入 localStorage；解读接口校验令牌后才下发付费章节。接入真实支付时，
只需替换 `confirm` 为支付回调并沿用同一套 HMAC 令牌签发逻辑。
